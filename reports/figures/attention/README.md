# P8-8 attention maps

Generated by `scripts/29_attention_maps.py` from `experiments/phase8_full/seed0/best.pt`.

**Selection is deterministic, not curated:** the highest-confidence correctly-classified
dev fakes, plus the two most confident correct reals as controls. Shaded bands are the
labelled `fake_periods`.

⚠️ These are qualitative. The number that belongs in a table is `attention_lift` in
`reports/phase8_full.json` — the mean attention weight on forged frames divided by the
mean on genuine frames, across all fake dev clips.
